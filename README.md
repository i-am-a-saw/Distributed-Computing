# Распределённые вычисления: учебные конспекты

Учебные страницы по курсу «Распределённые вычисления». Для каждой лекции и каждого семинара есть отдельная HTML-страница, которая превращает исходный конспект в удобный справочник.

## Что есть на каждой странице

- **Весь материал конспекта**, объяснённый простым языком, с прокомментированными листингами кода и схемами.
- **Исправления к конспекту.** Каждое утверждение проверено по официальным стандартам и документации. Найденные в исходном конспекте ошибки перечислены в начале страницы и исправлены в тексте.
- **Блоки «Сверх лекции» (Beyond the lecture).** Дополнительные сведения, которых нет в исходном конспекте, отмечены отдельно, чтобы всегда было видно, что взято из курса, а что добавлено.
- **Оригинальные термины курсивом**, чтобы страницу было легко сопоставить с исходным конспектом.
- **Шпаргалка** с ключевыми функциями и правилами на одном экране.
- **Вопросы для самопроверки** со скрытыми ответами. Сначала ответьте сами, затем нажмите, чтобы увидеть ответ.

## Как пользоваться

**Смотреть онлайн через браузер.** Из репозитория скачайте любой нужный html-файл. После этого страницы будут доступны к просмотру через любой установленный браузер.

**Советы по чтению**

- На широком экране переходите между разделами через оглавление слева.
- Страницы подстраиваются под светлую или тёмную тему системы.
- У блоков кода есть кнопка **Copy** для копирования.
- Шрифты загружаются с Google Fonts. Без интернета страницы работают с системными шрифтами.

## Отказ от ответственности

Это личные учебные материалы, а не официальные материалы курса. Содержание тщательно проверено, но если страница расходится со словами преподавателя, уточните у преподавателя.
